# Context Music Manager 1.0.5 — every change, most interesting first

One line per change. `[New]` an addition, `[Changed]` a behaviour or default, `[Fixed]` a bug,
`[Faster]` a performance change. Everything is measured against 1.0.4b.

---

1. **[New] Music through in-world speakers.** Radios, jukeboxes and speaker blocks play your Radio music where they physically stand, so a POI you are clearing has music coming out of the room instead of out of your head. Several stations sound at once, and every speaker on the same station is heard as one source in the right place.
2. **[New] A real acoustic model, not a distance fade.** One acoustic field floods out from the listener several times a second and every speaker reads it, so sound routes through doorways and around corners rather than through walls. Reverb around a corner is graded by how much energy survives the bounces — a stone cave carries it, an absorptive wood room kills it.
3. **[New] Personal radio.** `Alt+PgUp` / `Alt+PgDn` walk Off → station → station → … → Off, so two keys give on, off, next and previous. Non-spatial, in your head, on the same world-clock broadcast the speakers play — and it works on every supported version, including alphas with no speaker blocks at all.
4. **[New] Music packs can ship as their own mods.** CMM reads from your `MusicPath` **and** the `Music` folder of every installed mod, as one folder per context — so a soundtrack author publishes an ordinary mod that survives updating CMM and works with MO2, Vortex and Wabbajack.
5. **[Changed] A big library finally sounds like one: every track plays before any repeats.** `RandomNoRepeat` excluded exactly one track, so over 400 measured runs something came back after an average of 18 tracks and as soon as 3. Each context now deals from a shuffled bag and reshuffles only when it runs out.
6. **[Changed] Your config files are yours.** `settings.xml`, `radio.xml` and `contexts.xml` are no longer shipped in the archive — they are written on first run. Updating adds only what a new version introduced, under a banner saying which version added it, and leaves everything else alone. Previously every update silently reset every setting you had chosen.
7. **[Fixed] The game's Overall Volume slider now works on CMM's music.** CMM leaves through its own output device, so Unity's master never reached it — turning the master to zero silenced the whole game *except* this mod. Overall now applies to everything CMM emits and multiplies with the music slider exactly as vanilla does, matching it to well under a tenth of a decibel.
8. **[Fixed] Installing on a dedicated server no longer freezes joining players.** CMM is client-side only, but the full client stack used to start on a headless server with one hook on the world-load path, hanging every joining client at the loading screen. It now detects a dedicated server and stays completely inert, logging one line telling the admin it is safe to leave installed.
9. **[New] Subfolders of the Radio source are stations**, each its own pool, anchored to the shared world clock — so everyone on a server hears the same song at the same moment, and tuning in joins a broadcast already in progress. Stations start instantly whatever the pool size.
10. **[New] Changing station sounds like tuning a radio.** The station you leave sinks under rising static rather than being cut, the dial passes through noise, and the new one arrives band-limited and distorted before opening out into full fidelity.
11. **[New] The Context HUD now ships.** `Alt+Numpad9` cycles hidden → compact → expanded: what is playing, the tokens the script resolved, the fallback chain actually walked, the file it came from, and how much is staged and measured. It answers "why is this playing?" without reading a log. Previously it existed only in development builds.
12. **[New] A coverage panel** (`Alt+Numpad8`). One row per context: whether it has music, how many tracks, and the fallback chain it walks with the context you will actually hear marked at the end. Read live from disk, and it works on the main menu before a world is loaded.
13. **[Fixed] FLAC files with an ID3 tag would not play at all.** Plenty of tagging programs write an ID3 tag in front of the `fLaC` marker; those files play everywhere else and were silently skipped here. In one 9,839-file library, 146 were affected — and because tagging tools work an album at a time, they arrive in whole albums.
14. **[Fixed] Speakers stopped being detected, sometimes for the rest of the session.** The mod looked up the game's internal block ids once per session, but the game reassigns them every world load — so on the second world of a session every speaker went silent at once and only restarting fixed it.
15. **[Fixed] Live edits went unnoticed on exFAT, FAT, SD cards and many network shares.** Those filesystems do not update a folder's timestamp when files inside it change, so adding, removing or renaming tracks went unnoticed until a restart. All three watchers now use a listing-based signature there; NTFS keeps the cheaper fast path.
16. **[Faster] Decoder stalls on large video files.** An mp4's oversized `moov` index was parsed via millions of tiny reads (2 GB file: >25 s → 0.7 s), and mkv/webm demuxed the whole audio track into RAM at open (20 GB mkv: ~130 s → 0.2 s, peak working set 17 MB instead of proportional to file size). Output verified bit-for-bit identical.
17. **[Fixed] Music no longer starts at the wrong volume and slides into place a second later.** Playback now waits silently for the loudness measurement, up to `LoudnessStartHoldMs` (3 s), rather than starting uncorrected and easing the real level in underneath you.
18. **[Fixed] Tracks whose loudness had not been measured yet played at full level.** "Unmeasured" was treated as "already correct", which for a modern master is 8–12 dB too loud.
19. **[Fixed] Long tracks started at the wrong volume and stayed there.** A 37-minute podcast took nine seconds to measure — three times longer than the mod will wait — and played at a guess around 12 dB quiet for all of it. Long files are now measured in five-minute pieces; across 27 real files the first answer was within 0.82 dB of the final one, worst case.
20. **[Fixed] Radio music was quietly distorted.** The receiver's drive stage never fully switched off, so every fully-tuned station carried 2–7% distortion depending on how hot the track was — before the volume control, so turning it down did not remove it.
21. **[Faster] Starting a world speaker froze the game briefly.** Opening the file and skipping to the right point in the broadcast ran on the main thread — 403 ms for a station joining ten minutes into a podcast, and the worst stalls in a session were all speaker starts. Now in the background: under 9 ms.
22. **[Fixed] World speakers went quiet in the middle of a station change** *(RC4)*. The crossover had only one side: the speaker was held out of every station until the handover finished, so the old sound faded out over a full second with nothing under it and the new one appeared at full a moment later. Measured as a 180 ms hole with a step at each end.
23. **[Fixed] Ticking and popping when you turned your head near a speaker** *(RC4)*. A speaker's stereo position was recalculated once per audio block and applied flat across it, so turning quickly moved it a whole block's worth in one sample, over and over. It slides across the block now, with nothing delayed.
24. **[Fixed] Death and spawn stingers were delayed by up to three seconds** *(RC4)*. Audio under 400 ms cannot be loudness-measured at all, so the mod waited every single time for a measurement that could never arrive. You died, then three seconds of nothing, then the sting.
25. **[Fixed] World speakers could go silent for the rest of the session** *(RC4)*. Each time the station list rebuilt, a speaker holding one of the three audio slots without having started yet never gave it back. Three of those and nothing in the world played again, with nothing in the log to say why.
26. **[New] Speakers sound like speakers.** `WorldEmitterColorVoice` squeezes the sound into a small driver in a small box — band-limited hard at both ends with the boxy resonance a cheap cone actually has, rather than just quieter and duller. `ColorDrive` adds the crunch of one pushed too hard, `ColorStatic` a bed of hiss. Ham radios get their own harder-voiced set.
27. **[Changed] World speakers follow the Ambient slider**, with Overall. A radio playing out of a block is an environmental sound, so turning the *music* down no longer silences the radios in a POI.
28. **[New] The dial has recorded sounds** in the mod's new `Sounds/` folder — swap them for anything you like. Every firing plays at a slightly different rate, so spinning the dial sounds like a mechanism rather than one recording retriggered eight times. Synthesized clicks remain as a fallback: a sound file can quieten the radio, never break it.
29. **[Fixed] Re-encoding a radio track put the station out of step** *(RC4)*. Lengths were remembered by filename and never rechecked, so a replaced track left the station starting songs part way through — and on a server, players hearing different songs on the same station.
30. **[Fixed] A briefly disconnected drive could take a station off the air permanently** *(RC4)*, and could leave a context looking empty for the rest of the session. A drive that is not there is now told apart from a track that is genuinely gone.
31. **[Fixed] Music could stop after a track ended** *(RC4)*, until you walked into a different context — if the next track had been deleted, moved or was unreadable, the mod gave up instead of picking another.
32. **[Fixed] The radio kept playing after you switched it off** *(RC3)*. Dial fast enough that no station ever landed, then roll onto Off, and the buried station was revealed at close to full level and played its whole track with the radio showing Off.
33. **[Fixed] The radio no longer loses your place** *(RC3)*. Switching it on took over the music layer without noting where the track had got to, so switching off restarted the context on a different track from the beginning.
34. **[Changed] Massive contexts now crawl incrementally.** A `subfolders=true` context on a huge tree publishes a growing partial snapshot so it becomes playable long before the walk finishes, round-robins recursive contexts so one giant folder cannot starve another, and never enumerates on the frame thread.
35. **[Fixed] Occlusion changes arrived late, and by a different amount on every door.** The smoothing used a coefficient applied per audio buffer rather than per second, so its real time constant fell out of the device buffer size (~330 ms at 10 ms, ~660 ms at 20 ms) — and it was adaptive, running three to seven times faster on a closing door than an opening one. Now one time constant in seconds, the same everywhere.
36. **[Changed] Door timing was rebuilt around what a doorway actually opens.** A door's sound follows the measured open area of its doorway in square metres rather than a fraction of its animation, so a garage door and a closet door behave consistently without a per-door table.
37. **[Fixed] Changed settings now actually reach an existing config file.** The migration recognised only **one** previous default, so changing the same default twice stranded anyone who skipped the version in between — permanently, since it read as a deliberate override. Every former default is now recognised.
38. **[Fixed] Config files open correctly in text editors.** They are UTF-8 and always were, but were written without a byte-order mark, so Windows editors guessed Windows-1252 and every accented character, arrow and rule appeared as mojibake — a correct file that read as a corrupted one.
39. **[New] Every dead station sits on its own note** *(RC4)*. A station with nothing playable no longer parks on a single 440 Hz test tone: it is a minor triad (440 / 523.25 / 659.25 Hz, each a setting), and `WorldEmitterOffAirVarianceHz` moves the root per station, seeded from the station's name — so a dead channel keeps the same pitch every time you tune to it, on every client and across restarts.
40. **[Fixed] Static formed over the off-air tone and stayed there** *(RC4)*. The receiver keeps a faint bed of noise even when locked, which is right for a station and wrong for a speaker sitting on the tone with nothing else on it. The hiss now clears as the tone comes up.
41. **[New] Ban, favourite and combat-music keybinds.** `Alt+Delete` bans the playing track (persistent), `Alt+End` undoes the last ban 25 deep, `Alt+Insert` marks a favourite.
42. **[New] `Alt+Home` cycles fight music** through combat+tension off → combat off with tension on → both on. Tension is the stalking cue before a fight, so silencing fights while it keeps running only moves the noise — which is why one key covers both. Saved across restarts.
43. **[Changed] `FavouriteWeight` is scaled to folder size**, so a favourite means roughly the same thing — about once an hour of play — whether the folder holds fifty tracks or five thousand, instead of becoming meaningless in exactly the large libraries it matters most in.
44. **[New] Per-context play history for Next/Prev.** The skip keys walk back and forward through what you actually heard in that context, like a music player, instead of rolling a fresh random track.
45. **[New] Playlist sources.** A context's `source` may name an `.m3u`/`.m3u8` instead of a folder, so one playlist draws tracks from anywhere on disk without moving or copying them. Re-read when it changes.
46. **[New] Now Playing overlay.** A small top-left readout of track and context, `Alt+Keypad7`. Hides during a single-player pause and while the F1 console is open — both cover the same corner — and returns exactly as it was.
47. **[Changed] An infested POI now carries its ordinary tier music underneath it.** `POI_T1`–`T5` used to be excluded outright while sleepers were alive, so an empty infested folder left nothing POI-shaped to fall back to. Both are active together now, and they share a warm-up dwell so the plain tier no longer gets audibly displaced a moment after starting.
48. **[Fixed] Vanilla fallback could hold the wrong music for minutes near a trader.** After handing off *to* vanilla, CMM's section hold kept applying — pinning the game to whatever section was current at the handoff, observed for minutes at Trader Rekt.
49. **[Fixed] Disabled trader dropped combat music to Exploration.** In a trader's area the game proposes the trader section even mid-combat, so with the trader disabled the blind fallback played exploration music during a fight.
50. **[Fixed] Music that came and went was cut off before it had finished arriving** *(RC3)*. Contexts driven by things that vanish in seconds had 3–5 second fade-ins but are dropped 1.5 s after their trigger goes, so a flicker cancelled the fade a third of the way up and you never really heard it.
51. **[Fixed] Two station loads could run at once and one of them was lost** *(RC3)*. The hand-off is a single slot with a ten-second safety net, and a large FLAC on a network drive is slow enough to trigger it — the second load overwrote the first, whose audio then played on unattended.
52. **[Fixed] A station could be added after the radio had already been switched off** *(RC3)*. The guard checked whether the dial had moved but not whether the radio was still on.
53. **[Fixed] Leaving a world kept its acoustics in memory** *(RC3)*. Per-speaker sound maps were never released — up to ~43 MB held indefinitely — and a speaker at the same coordinates in a different world could be handed the old world's map.
54. **[Fixed] Replacing a music file kept the old file's volume** *(RC4)*. A re-encode or a real track over a placeholder played at whatever the old one needed; permanent if you had ever adjusted that track yourself.
55. **[Fixed] A part-read file could set a wrong volume permanently** *(RC4)*. If a drive dropped out mid-scan, the fraction that had been read was recorded as though it were the whole track.
56. **[Fixed] A track that could not be read was retried once a second, forever** *(RC4)* — a full re-read of the file each time. It now backs off.
57. **[Fixed] Playlists quietly losing tracks are now visible** *(RC4)*. Entries pointing at moved files were dropped in silence unless *every* entry failed; the coverage panel now shows `9 of 12 — 3 missing` and lists them in gaps-only mode.
58. **[Fixed] `Cache/loudness.xml` grew far larger than intended** *(RC4)*. It was meant to hold only tracks you had adjusted, banned or favourited, and was accumulating an entry for every track played.
59. **[Fixed] Loudness measurements are kept between sessions again.** They had stopped persisting, so the track resuming at world entry re-measured every launch.
60. **[Fixed] A hint of the main-menu theme could be heard while paused.** The game fades the title theme in over the single-player pause screen, and it slipped through CMM's pause silence while the vanilla fallback was active.
61. **[Fixed] A track ending during a pause unmuted everything.** The pause silence is a device-wide gain duck and starting any new audio revived it, so a track auto-advancing mid-pause became audible through the pause screen.
62. **[Fixed] Fully-silenced spawn stingers bled in right at their end.** With `VolumeModifier` at 0 the stinger's last seconds became audible during its release fade, because volume ownership flips while the released voice is still fading.
63. **[Fixed] Recursive menu music never left the vanilla bed on a huge tree.** The menu reclaim only ran after a full sweep — minutes away on hundreds of thousands of files — and now also runs on the crawler's partial publish.
64. **[Fixed] A misleading "none decodable" warning** *(RC3)*. A station that was simply still preparing reported that its files could not be decoded and told you to check their format.
65. **[Changed] The static from world speakers is half as loud** *(RC4)*. It was set against the hiss from the radio in your pocket, which reaches your ears by a different path — a world speaker's noise arrives before distance, occlusion and the room are applied. The personal radio is untouched.
66. **[Changed] World speakers default to half volume** *(RC3)*. They were at full to compensate for an occlusion bug that has since been fixed twice over, so the compensation was counted twice. A value you chose yourself is kept.
67. **[Changed] `WorldEmitterFieldDetourDb` stays at 1.5** *(RC3)*. At the 3 that RC2 shipped, one right-angle corner cost 29 dB against a real single-edge diffraction loss of 10–15 dB, and sound stopped travelling far enough through a building.
68. **[Fixed] The muffle arrived after the level.** Tone and level are now slewed on the same time constant, so an occlusion change lands as one event instead of two.
69. **[New] Per-section switches for vanilla Dynamic Music.** `DisabledVanillaSections` turns off individual sections (Exploration, Suspense, Combat, Bloodmoon, Trader…) rather than all-or-nothing.
70. **[New] Richer game-state snapshot for `context.lua`** — POI tier and infestation, trader identity, vehicle, weather, biome, threat detail. Documented in `Config/context.api.md`.
71. **[Changed] The Music folder tree is created by the mod, not the installer.** Per-context folders appear where your music actually lives rather than only inside the mod folder, and contexts you add yourself get folders too. Never writes into an existing folder, never deletes, and skips entirely if `MusicPath` is on a detached drive.
72. **[New] `cmm roots`** lists which folders are in use and which mod each came from; `cmm roots <context>` breaks down what each contributes — the fastest way to answer "why isn't my pack playing".
73. **[New] `cmm scan`** looks for music folders again, for a pack added while the game is running. It finds packs the game itself has not loaded: a music pack is data, so there is no reason to make you restart for one.
74. **[New] `cmm rotation`** shows how far each context is through its pass and how many tracks remain; `cmm rotation reset` starts them over.
75. **[New] `cmm acoustics`, `cmm field`, `cmm emitters`** show and tune the acoustic model while you listen. `cmm sfx` shows which dial sounds loaded; `cmm sfx test spin` fires eight detents in a row.
76. **[New] `TrackNoRepeatMemory`** tunes the shuffle: `-1` (default) is the whole folder, `0` restores the old one-track behaviour exactly, any other number remembers that many recent tracks. `Random` and `Sequential` are unchanged.
77. **[Changed] Every Harmony patch body is exception-contained.** A CMM failure inside a vanilla lifecycle method can no longer abort it — the game always completes the spawn, CMM logs the suppressed error rate-limited and recovers on its next scan tick.
78. **[Changed] The world polls tolerate the partial game state a multiplayer client sees mid-join**, including the game's own unguarded chunk-provider dereference on unstreamed chunks.
79. **[Fixed] The native mixer no longer opens or closes the audio device while holding its global lock.** A wedged Windows audio endpoint used to freeze the main thread at exactly the spawn moment; a stalled driver now delays music, never the game.
80. **[Faster] Lower resolve-tick GC.** The per-tick snapshot marshal caches each scalar field and re-sends only what changed, instead of boxing ~20 values every scan tick — roughly 20 allocations down to 1 while roaming.
81. **[New] A centre-screen announcement** when combat/tension music is muted or unmuted, rather than the corner box used for small confirmations. Both timings are settings.
82. **[Changed] CMM's keys go inert while the F1 console is open.** Scrolling the console is PageUp/PageDown and numpad digits are ordinary typing, so a binding could change your music underneath a command you were writing.
83. **[Changed] Debug keybinds moved** to make room for the coverage panel: coverage on `Alt+Numpad8`, context HUD on `Alt+Numpad9`, its GC re-arm on `Alt+Numpad6`. Existing files are migrated, and both panels show their live keys in their own header.
84. **[Fixed] Wrong/missing context music on Turkish and Azerbaijani locales.** Culture-sensitive `ToLower()` meant the Turkish-i rule stopped strings containing "i" (such as `EntityMinibike`) matching the ASCII literals.
85. **[Fixed] Wrong game option read on A20/A21.** `EnumGamePrefs` member ordinals differ between game versions and the single cross-version DLL bakes compile-time values in, so the "is vanilla Dynamic Music enabled" check read a different, unrelated option.
86. **[New] 7 Days to Die 3.2.0 b9 support.** Compiles and ships against 3.2 with no source changes — nothing in the game API it touches moved between 3.1 and 3.2.

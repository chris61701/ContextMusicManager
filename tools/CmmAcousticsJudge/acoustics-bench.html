Model notes

CMM is the shipped code, ported: material-weighted flood (Dijkstra) with boundary blend, tanh soft-knee + hard-stop gate, occlusion-as-virtual-distance falloff, air-route depth grading, and the two-bus reverb (local = fed the arriving occluded signal; carry = seal-gated + material-damped next-room cue).

Reference is idealized physics: spherical spreading over the geodesic path + per-material transmission loss in dB, reverb from enclosure/absorption. It ignores engine constraints — the point is the Δ view: red = CMM louder than physics, blue = quieter.

Tune Lab — the sound between stations

Loops the exact thing the game does: fade the station out, roll static while the next one opens, fade it in. The static generator is ported sample-for-sample out of cmm_mix.c, so a number settled here is the same number in the game.

idle
A press space to swap, mid-loop B

The swap does not restart the loop — you hear the change at the same point in the same movement, which is the only way to judge one variable at a time.

The static these four are in the game today

Between stations there is no carrier, so the noise comes out flat and de-emphasis tilts it down above its corner: a dark, full-bodied roar. A weak station is the opposite — a bright thin hiss. Low cut is clamped to 50 Hz in the C, so anything under that reads as 50.

The sequence timings, in milliseconds

Shipped: fade out 250 ms (ManualSkipFadeDuration), static pinged every 250 ms and seamless, open+seek measured at 50–130 ms for a mid-file mp3 but longer in practice. Load time is the one you cannot control in the game — so find out how long is tolerable.

Tuning in and out not built yet — this is what it would sound like

Today the station is a plain volume fade. A real receiver goes dull and mono on the way out and arrives dull and mono under the noise before opening up. Set both to 0 to hear exactly what ships now; raise them to hear what building it would buy.
